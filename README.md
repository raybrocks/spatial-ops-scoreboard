# Run and deploy your AI Studio app

This contains everything you need to run your app locally.
https://ai.studio/apps/e4b9c1c9-7bd0-48da-9796-2c2589cf2abc

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev` (This will always run on port 3001 locally: `http://localhost:3001`)

## Git Workflow
This project is managed with an AI assistant. To commit and push changes, simply tell the AI: **"git push"**. The AI will automatically stage all changes, generate a commit message, and push to the `main` branch.
